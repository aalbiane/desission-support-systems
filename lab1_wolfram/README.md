# Лабораторная работа №1. Интеграция Wolfram Alpha через API

Программа на Python подключается к Wolfram Alpha Full Results API, выполняет
15 запросов (10 обязательных и 5 по выбору), извлекает из JSON-ответов ключевые
данные, выводит их на экран и сохраняет в файлы.

## Структура

| Файл | Назначение |
|---|---|
| `config.ini` | настройки и API-ключ (AppID) |
| `config.example.ini` | образец файла настроек без ключа |
| `config.py` | модуль конфигурации: чтение `config.ini` |
| `queries.py` | список запросов |
| `wolfram_client.py` | модуль запросов: HTTP-клиент, обработка ошибок сети и API |
| `response_parser.py` | модуль обработки: разбор JSON, извлечение ключевых данных |
| `storage.py` | сохранение полных ответов и извлечённых данных |
| `main.py` | точка входа, журналирование |

## Запуск

1. Установите Python 3.9 или новее.
2. Установите зависимости: `python -m pip install -r requirements.txt`
3. Впишите свой AppID в `config.ini` (раздел `[wolfram]`, параметр `app_id`).
   AppID выдаётся на https://developer.wolframalpha.com (Get an App ID, Full Results API).
4. Запустите программу: `python main.py`

В Windows можно просто запустить `run.bat`: он установит зависимости и запустит программу.

## Результаты

- `results/raw/NN_<запрос>.json` - полные ответы API, по файлу на запрос;
- `results/results.json` - извлечённые данные в формате JSON;
- `results/results.txt` - те же данные в удобочитаемом виде;
- `logs/wolfram.log` - журнал выполнения.

## Обработка ошибок

- нет `config.ini` или не указан ключ - программа сообщает об этом и завершается;
- сетевая ошибка или тайм-аут - запрос повторяется (число повторов задаётся в `config.ini`);
- ошибка API (например, неверный AppID) - записывается в журнал, программа переходит к следующему запросу;
- запрос не распознан Wolfram Alpha - в результатах ставится отметка «Запрос не распознан».
