# Лабораторная работа №3. Нечёткая экспертная система анализа погоды

Программа получает текущую погоду Казани, Москвы и Санкт-Петербурга
(OpenWeatherMap), историю за последние годы (Open-Meteo), считает сезонные
нормы, выполняет нечёткий вывод Мамдани (scikit-fuzzy), выявляет аномалии,
формирует рекомендации и строит графики.

## Структура

| Файл | Назначение |
|---|---|
| `config.ini` | API-ключ OpenWeatherMap и число лет истории |
| `cities.py` | справочник городов, определение сезона |
| `weather_api.py` | запросы к OpenWeatherMap и Open-Meteo |
| `climate.py` | сезонные нормы, многолетний архив, аномалии |
| `fuzzy_system.py` | нечёткая система: переменные, термы, правила, вывод |
| `linguistic.py` | перевод чисел в лингвистические значения |
| `recommendations.py` | рекомендации |
| `visualization.py` | графики |
| `main.py` | точка входа |
| `data/` | многолетний архив метеостанций из «Погода.zip» |

## Запуск

1. `python -m pip install -r requirements.txt`
2. Впишите свой ключ OpenWeatherMap в `config.ini`.
3. `python main.py`

В Windows можно запустить `run.bat`.

## Результаты (папка `results`)

- `report.txt` - полный текст вывода программы;
- `results.csv` - итоговая таблица;
- `seasonal_norms.csv` - сезонные нормы;
- `membership_<город>.png` - функции принадлежности;
- `seasonal_profiles.png` - сезонные профили;
- `trends.png` - тренды среднегодовой температуры;
- `comfort.png` - итоговый уровень комфорта.
